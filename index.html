🎵 yt2minecraftdisc converter

A file goes in, a file comes out. Everything happens in this tab: Gradio runs on Pyodide and the conversion runs on ffmpeg.wasm, so nothing is uploaded anywhere. The first visit downloads both — about 30 MB and a few seconds — and the browser caches them after that.

# The Static Space has no server to run this file, so this is all of it: fetch # the project's own Python off the Space, put it where sys.path can see it, hand # ffmpeg over to WebAssembly, and then run the real app.py unchanged. import re import sys from pathlib import Path import js from pyodide.http import pyfetch SOURCES = ( "app.py", "core.py", "webapp/converter.py", "webapp/browser_ffmpeg.py", "webapp/packs.py", ) ROOT = Path("/yt2disc") def space_url(): """This Space's own address, so a fetch cannot miss the files. Python runs in a worker here, so `location` is the *worker's* - usually a blob: URL - and a bare relative fetch would resolve against that rather than against the page. The origin inside it is the part worth keeping, and an empty answer just leaves the URLs relative, which is right when the worker is served straight from the Space. """ href = str(getattr(js.location, "href", "") or "") found = re.match(r"(?:blob:)?(https?://[^/]+)", href) return found.group(1) if found else "" base = space_url() (ROOT / "webapp").mkdir(parents=True, exist_ok=True) for name in SOURCES: url = f"{base}/{name}" if base else name response = await pyfetch(url) if not response.ok: raise RuntimeError(f"could not fetch {url}: HTTP {response.status}") (ROOT / name).write_text(await response.string(), encoding="utf-8") sys.path[:0] = [str(ROOT), str(ROOT / "webapp")] import browser_ffmpeg browser_ffmpeg.prepare() await browser_ffmpeg.install() import app app.build_demo().launch()
